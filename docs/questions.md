### Access checklist

For each item the client picks one of: **Granted**, **Will do**, **Do not have**, **Need help**.

**Domain registrar**

Invite us as a user, or move the domain into your own account and add us. GoDaddy, 123-reg, Namecheap and Cloudflare all support this.

**Web hosting**

Most hosts allow a second login or sub-account. If yours does not, use the one-time link at the bottom of this page.

**Existing website admin**

In WordPress: Users, Add New, set role to Administrator. Squarespace, Wix and Webflow have an equivalent invite.

**Google Business Profile**

Business Profile, Settings, People and access, Add, then choose Manager.

**Google Analytics**

Admin, Property access management, add our email as Editor.

**Google Search Console**

Settings, Users and permissions, Add user, Full.

**Facebook and Instagram pages**

Meta Business Suite, Settings, People, invite our email with Content access. This covers your pages — ad accounts are separate, further down.

**Google Tag Manager**

Admin, User Management, the + button, Add users, then give Publish permission on the container. If you have never heard of Tag Manager you almost certainly do not have one — mark it Do not have and we will set it up.

**Google Ads**

> Sent to **dmorgan18@googlemail.com**, not the address given above.

> Only shown if they already run ads.

Admin, Access and security, the + button, enter the email and choose Admin. Google sends an invitation that has to be accepted, so it will not show as active straight away.

**Meta Ads account**

> Sent to **dmorgan18@googlemail.com**, not the address given above.

> Only shown if they already run ads.

Meta Business Suite, Settings, Ad accounts, pick the account, Add people, then turn on Manage campaigns. This is separate from page access above — granting one does not grant the other.

**TikTok Ads**

> Sent to **dmorgan18@googlemail.com**, not the address given above.

> Only shown if they already run ads.

TikTok Ads Manager, Assets, Users, Invite, and choose Admin.

**Booking system**

Add us as a staff or admin user so we can wire the booking flow into the new site.

**Email marketing**

Mailchimp, Klaviyo, Brevo and similar all support inviting a second user.

**Payments**

Stripe, Settings, Team, invite as Developer. Only needed if the site takes payment.
